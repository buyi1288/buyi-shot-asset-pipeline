# 分镜提示词包 · 格式规范

写第 3 步时用。核心铁律：**每段末尾逐字抄完整四段锁**，禁止"（同前，略）"。

## 一、文件头参数

| 项 | 设置 |
|---|---|
| 画幅比例 | 16:9 |
| 单段时长 | 10 秒 |
| 分辨率 | 1080p（1920×1080） |
| 帧率 | 24fps |
| 生成模式 | 文生视频（无参考图，角色外观靠文字锚定）；有上一单元成片时用"视频延长" |
| 单段图片参考上限 | ≤9 张 |
| 音频 | 只生成对白原声、环境声、同步音效；不生成 BGM；不生成字幕 |

## 二、资产编号对照表（放在文件开头）

| 编号 | 名称 | 类型 | 出图 |
|---|---|---|---|
| CHxxx | 角色代号 | 角色四视图 | 21:9 横图 |
| SCxxx | 场景代号 | 空场母版 | 16:9 |
| PRxxx | 道具代号 | 设定图 | 4:3 |

编号跨篇延续，不因新故事重置：旧篇已用 CH001，新角色从 CH002 起；场景、道具同理。

## 三、单段结构

```
# S01｜00:00—00:10｜【单元标题】

- 对应剧情：第 N 场｜10 秒｜N 镜
- 台词时长检查：本单元对白约 N 字，10 秒从容（>60 字需精简）

【视频风格：一句话写环境/材质/光影】
素材：CH001 角色A｜SC001 场景一｜PR001 道具一
视频第一帧可见状态：第 0 秒画面里看得见的事实
0-4秒｜35mm 中景，机位与运动｜主体动作｜对白/情绪/光影
【角色外观锁】
【声线锁】
【最高优先级·嘴型规则】
【硬禁止】
禁止生成BGM.禁止生成字幕】

- 段末状态：本段最后 1 秒的画面事实（承接下一段首帧）
```

素材行只写"编号 + 名称"，不加括号注释。

### 镜头行格式

`时间｜焦段景别·机位·运动｜画面主体动作｜对白/情绪/光影`

示例：

`0-4秒｜35mm 中景，机位在桌侧、眼平，固定｜角色A 在桌前｜角色B 问"这东西你从哪弄来的？"；角色A 答"先别问。"；暖黄灯光打下，蒸汽升起。`

## 四、台词语速铁律

- 10 秒按 **2–5 字/秒** 写（10 秒 20–50 字）才从容。
- 某段超过 60 字（>6 字/秒）判定过密，必须精简。
- 精简顺序：先砍重复解释，再砍过渡词，最后保留信息量高的实词；但对话必须接得住——上一句问什么，下一句先回答再补因由，不能跳。

## 五、四段锁模板（每段末尾逐字抄，填好值后一字不改）

### 【角色外观锁】

每个角色一句，八个字段填满：

`角色A = 【体色】【体形】Q 版身体，【耳朵：数量+形状+是否被遮挡】，【眼睛：形状+颜色】，【固定嘴型】，【腮红：有无+颜色+位置】，【配饰：有无+颜色+位置】，【手：颜色+是否分指】，【禁止项：鼻/眉/发/爪/趾/物种专属特征】。`

### 【声线锁】

`角色A = 【音色】【年龄感】；禁止【沙哑/低沉/成熟/粗犷……按需列出】。`

### 【最高优先级·嘴型规则】

`所有表情、说话、情绪都只能通过【固定嘴型】表现。说话：【固定嘴型】轻微开合，不变形；笑：末端轻微上扬，不变成圆嘴；嗔怪：轻微收紧，不变成噘嘴；惊讶：轻微拉开，不变成大张嘴。绝对禁止用任何偏离【固定嘴型】的嘴形表达情绪。`

### 【硬禁止】

`禁止鼻子、禁止物种专属特征（如熊鼻/熊爪/爪垫）、禁止动物肢体/爪子/手指/脚趾、禁止头发/眉毛、禁止偏离固定嘴型的所有嘴形（O 型/圆嘴/方嘴/大张嘴/嘟嘴/噘嘴/前突唇/双层嘴/撇嘴线）、禁止 3D 渲染、禁止写实、禁止厚涂、禁止水墨、禁止血腥暴力恐怖、禁止崩脸变形、禁止金光刺眼浮夸、禁止模糊抖动跳切。`

### 结尾

`禁止生成BGM.禁止生成字幕】`

> 新增非人角色时，其外观锁单独写一条（可保留该物种的爪子/眼圈等特征），主线角色的四段锁仍逐字抄录。
