## 二、编号与比例

| 前缀 | 含义 | 示例 | 出图比例 |
|---|---|---|---|
| CH | 角色 | CH001_角色A | 四视图 21:9 横向宽图 |
| SC | 场景 | SC001_场景一 | 空场母版 16:9 |
| PR | 道具 | PR001_道具一 | 设定图 4:3 |

- 编号**跨篇延续**，不因新故事重置。
- **场景母版必须空场**：只画环境/空间/家具/固定物，禁止人物、动物、动态人群。
- 新角色若已有参考图，把造型文字化后再写进 prompt；非人角色可保留该物种特征，主线角色仍守自己的禁止清单。

## 三、单条资产 prompt 结构

```
生成一张【角色四视图/空场景母版/道具设定图】，【比例】，
【背景：影棚灰/中性浅灰/深灰】。

主体：【角色/场景/道具】的【外观细节/空间结构/形态】。
【关键识别点：固定嘴型/配饰/单实例等】
【姿态/摆放状态】

光线：【光源方向、亮暗、色温】
风格：日式手绘水彩二维动画，Q 版圆润造型；
粗而干净勾线，平涂加柔和渐变，水彩质感；非真人照片质感，非 3D 塑料感。

限制：【必须保持/禁止出现】
负面提示词：【逐项列出，逗号分隔】

【清洁渲染尾缀】
```

## 四、清洁渲染尾缀（每条图片 prompt 末尾逐字附）

```
clean illustration, smooth shading, soft lighting, controlled details, minimal texture, high clarity, refined edges, smooth gradients, hand-drawn anime style, watercolor background, flat cel shading --no noise, grain, artifacts, high frequency detail, dirty texture, oversharpen, blotchy, chaotic details, 3D, photorealistic.
```

> 尾缀必须跟在每条独立图片 prompt 末尾，不能只写在文件总纲。角色四视图可在尾缀后追加 `, human nose, human mouth` 双重保险。

## 五、道具单实例锁

若某道具全片只允许一个，在 prompt 末尾标注：

`【单实例锁：全片仅一个】`

并写清"PR 图只补外观，不新增第二件道具"。

## 六、素材行与资产编号对齐

- 分镜包每个单元"素材"行出现的资产名 → 资产包必须有对应编号条目。
- 资产包"逐段引用表" → 必须与该段素材行完全一致。
- 逐段核对，漏了任一出现的角色/场景/道具就补齐。

## 七、负面提示词常用清单（按需取用）

人物，真人照片感，3D 塑料感，厚涂，水墨，网红大眼，现代服装/都市，乱码文字，水印，logo，低清晰度，噪点，过度锐化，多余肢体，崩脸变形，多人，换脸；角色类追加：鼻子，鼻孔，头发，眉毛，手指，脚趾，爪子，爪垫，O 型嘴，圆嘴，大张嘴，噘嘴，嘟嘴，人嘴，人类面孔，写实人体。
